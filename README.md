# QA Automation Traineeship — Python

Technical task for the QA Automation traineeship.

## Requirements

* Python 3.x

## How to run

Clone the repository and run:

```bash
python main.py
```

The program provides interactive input through the console.

## Tasks

The program contains three tasks:

1. If the entered number is greater than 7, it prints `Hello`.
2. If the entered name is `John`, it prints `Hello, John`; otherwise, it prints `There is no such name`.
3. From the entered numeric array, it outputs elements that are multiples of 3.

## Bracket Sequence

Given:

```text
[((())()(())]]
```

### 1. Can this sequence be considered correct?

No. The bracket sequence is incorrect because the opening and closing brackets do not match correctly.

### 2. What needs to be changed to make it correct?

The sequence can be corrected by replacing the final `]` with `)`:

```text
[((())()(())])
```

This makes the brackets properly matched.
